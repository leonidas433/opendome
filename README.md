# OpenDome

Calculador gratuito de domos geodésicos para construcción en madera.
Subdominio de [bosqhabitat.es](https://bosqhabitat.es).

## Qué calcula

- Geometría exacta: frecuencias 2V, 3V y 4V (método Kruschke)
- Longitudes de listón por tipo (A, B, C...)
- Ángulos de corte: Método A (Kupulart, 2 máquinas) y Método B (sierra radial)
- Visualización 3D interactiva

## Stack

Astro 6 · React 19 · TypeScript · Tailwind 4 · Three.js

## Deploy

`domo.bosqhabitat.es`

## Dev

```bash
npm install
npm run dev
```
